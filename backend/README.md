# Back-End - SMAK Santa Agnes

Modul layanan server & RESTful API (Back-End) untuk Sistem Informasi Akademik SMAK Santa Agnes.

## Spesifikasi & Arsitektur
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MySQL via Prisma ORM
- **Fitur Terintegrasi**:
  - Firebase Cloud Messaging (FCM)
  - Scheduler / Cron Jobs (`node-cron`)
  - File Upload Handler (`multer`)
  - Autentikasi & Otorisasi

## Menjalankan Server
```bash
npm install
npm run dev
```
