# Front-End - SMAK Santa Agnes

Modul antarmuka pengguna (Front-End) untuk Sistem Informasi Akademik SMAK Santa Agnes.

## Spesifikasi & Arsitektur
- **Platform**: Android Native
- **Bahasa Pemrograman**: Kotlin (Minimal SDK 24 / Android 7.0+)
- **Local Caching / Offline Storage**: Room Database
- **Komunikasi Data**: RESTful API (JSON via HTTPS)

## Panduan
Letakkan *source code* project aplikasi Android (Android Studio) di dalam folder ini.
